YOLOv8-Pose
实时姿态检测系统

基于 YOLOv8-pose 的图形化姿态估计工具。支持图片、摄像头与本地视频输入，实时检测人体关键点、绘制骨架，并识别低头、驼背、身体侧倾等坐姿。

  • Python 3.8+
  • 17 个 COCO 关键点
  • MIT License
  • Ultralytics YOLOv8
⬇ 下载 v1.0.0 查看源码

核心功能

从输入到判断，全流程在本地完成。

🖼️

多种输入源

支持图片、摄像头与本地视频（.mp4 / .avi / .mov）。

🦴

关键点与骨架

基于 YOLOv8-pose 输出 17 个 COCO 关键点并绘制骨架。

🧍

坐姿分析

依据颈部、躯干与肩部角度，判断低头、驼背和左右侧斜。

👥

多人检测

画面中的多个人体可同时识别、标注与计数。

🎛️

实时调参

Tkinter 界面可调置信度、IOU 与姿态判断阈值。

⚡

实时性能

摄像头模式下可流畅运行，满足课堂与日常使用。

识别能力

用简单规则把关键点转化为可读的姿态结论。

17COCO 关键点
5坐姿状态
3输入方式
30fps+摄像头实时
正常坐姿 低头 驼背 左侧斜 右侧斜

快速开始

三分钟在本机跑起来。

1

下载并解压

获取 v1.0.0 源码包，或直接克隆仓库。

2

安装依赖

建议使用 Python 3.8+ 的虚拟环境。

3

启动程序

运行 GUI，载入模型后打开图片、视频或摄像头。

git clone https://github.com/aaron888hacker/-yolov8-.git
cd -- -yolov8-
pip install -r requirements.txt
python src/main.py
GitHub Pages 只托管本介绍页。姿态检测程序依赖 Python、OpenCV、PyTorch 等运行环境，需要下载后在本地运行。
